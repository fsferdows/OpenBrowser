## Reporting Issues

When filing a bug report, please provide:
1. Agentic Browser version and release channel (`LTS`, `Stable`, `Beta`).
2. Operating System and architecture (`macOS arm64`, `Windows x64`, `Linux x64`).
3. Exact steps to reproduce the issue.
4. Redacted logs: **Never include personal data, credentials, or API keys in issue reports.** The built-in log exporter automatically scrubs known secrets.

---

## Security Vulnerabilities

Please do **NOT** report security vulnerabilities via public issue trackers.
Follow the coordinated disclosure procedure in [SECURITY.md](file:///Users/user/Desktop/browser/SECURITY.md).
