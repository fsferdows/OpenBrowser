# Changelog

All notable changes to the Agentic Browser project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

  - `public/style.css`: Comprehensive responsive styling across viewports (`@media (max-width: 1200px)`, `@media (max-width: 992px)`, `@media (max-width: 768px)`, `@media (max-width: 480px)`). Fixed popovers (`.shields-popover`, `.ssl-popover`, `.rewards-popover`, `#cdp-popover`) with responsive right/left alignment and max-width bounds to prevent off-screen clipping. Added fluid toolbar button collapsing and mobile bottom-sheet layout.

Injected aggressive `brave-shields-adblock` styles and stripped ad network scripts (`googlesyndication`, `doubleclick`, `adservice`, `taboola`, `outbrain`) to remove video ads, banner ads, and sponsored overlays.

Intercepts and records clicks, typing, navigation, and form submissions in real time (`BRAVE_USER_ACTION`). Allows saving captured workflows as reusable skills and replaying them autonomously with animated cursor visualization.
